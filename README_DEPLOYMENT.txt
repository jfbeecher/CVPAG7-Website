Central Valley Project Agave Growers 7 LLC — Netlify Deployment Package

How to deploy:
1. Go to https://app.netlify.com/drop
2. Drag this entire folder OR the ZIP file into Netlify.
3. After Netlify deploys it, open Site configuration > Domain management.
4. Add your domain: centralvalleyprojectagave.com
5. At Network Solutions, update DNS to the records Netlify provides.
6. In Netlify, enable HTTPS after DNS has propagated.

Included:
- index.html
- optimized image assets
- Netlify contact form
- SEO metadata
- social sharing image metadata
- robots.txt
- sitemap.xml
- netlify.toml
- www-to-root redirect
- success page for form submissions

Optional edits before launch:
- Add Google Analytics / GA4 measurement ID if desired.
- Update contact names/phone/email if needed.
